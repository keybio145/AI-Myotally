# AI-Myotally v1.0.0 — Figure 3/4 and PCA reproduction

This additional reproducibility archive contains six-section four-channel IF TIFFs (Laminin, Myh4, Myh2, Myh7), final label TIFFs, the restored 35-column measurement table, sanitized Old 3/Young 1 editor checkpoints, fixed panel SourceData and downstream scripts. The existing Windows executable and generic postanalysis release remain separate, unchanged files. Application source, trained RF models, validation ROI-to-section keys and Figure 5 are excluded.

Use Python 3.11.9 and the pinned requirements-lock.txt in an isolated environment. Extract to an ASCII-only path for application/OpenCV compatibility. Run `python -B run_reproduction.py --output NEW_DIRECTORY` to verify manifests, restored measurements, final masks, Figure 4 numerical sources and PCA expected values, and generate Figure 3 display panels. Use `--render-figure4` to additionally regenerate Figure 4 panel previews. All output directories must be new. Run `python -B -m unittest discover -s tests -v` and `python -B -m unittest discover -s pca/tests -v` for tests.

The measurements are fiber types obtained by image-level calibration with the saved operator labels; values used for Figure 4 and Representative Results section 4. See docs/MEASUREMENT_AND_STATE_SCOPE.md for the eight restored columns and limits on replay. The original app-saved measurement CSV is not included. The PCA reference numbers came from the preserved 27-column reference input; the extra eight metadata columns do not enter the PCA. Both input identities are recorded separately.

Figure 4B uses the pointwise median of three interpolated animal ECDFs on a 260-point facet-specific common CSA grid. Figure 4C violins and median bars use pooled fibers; white circles are animal medians. The separate animal-summary CSVs provide descriptive composition and morphometry summaries. Figure 4F is pooled descriptive PCA. There are no inferential tests or independent classification validation claims in these figures.

Panels and SourceData are generated by scripts; final Figure 3/4 assembly and label editing were performed in Affinity Designer. Script output is not a byte reconstruction of the finalized PDF. The corrected final Figure 4 PDF is bound by SHA256 in figure4/FIGURE4_FINAL_BINDING.json; the five nonzero Type I segments have been checked against the numerical expected values. No artwork is edited by the reproduction scripts. Figure 5 is outside this archive's scope.

Saved operator type labels and per-image calibration parameters are supplied in data/calibration. Figure 3 presentation-window provenance and expected saved-stage image hashes are documented in docs/FIGURE3_REPRODUCTION_SCOPE.md.

When preparing the final measurement table, saved type labels on 2 objects that are not in the final table were not applied.
