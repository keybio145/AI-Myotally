# AI-Myotally v1.0.0 — reproducibility supplement, 2026-10-15

Application version: AI-Myotally v1.0.0. This archive date identifies supplementary materials, not a new executable build.

The archive provides six-section original IF channels, final label TIFFs, the restored 35-column measurement table and decision metadata, sanitized Old 3/Young 1 saved checkpoints, Figure 3 display scripts, Figure 4 SourceData and renderers, and 12-feature and 8-feature descriptive PCA scripts with expected values and pinned dependencies. The Windows executable and generic postanalysis ZIP are distributed separately. Application source, trained RF models, validation ROI-to-section keys and Figure 5 are excluded.

Final panels were assembled and labels edited in Affinity Designer. Scripts reproduce panel content and numerical sources, not final PDF bytes. The corrected Figure 4 reference has SHA256 3ec8dea39b4b072b397b7a51a3a38e84318cd7530949331e68560dd0004a0892. The five nonzero Type I segments align with the expected baseline; all other vector marks and page text are unchanged from the preceding reference.

The exact-application local CSA CV comparison had a maximum absolute difference 0.018 percentage points (unrounded 0.0181480137947644). This compares recalculated local CV with exported saved local CV values; it is not a PCA error or a between-group test.

Reanalysis from raw images can differ because interactive decisions and calibration must be reproduced. Saved checkpoints preserve endpoint decisions and selected stages; the chronological history of individual edits is not saved. The supplied calibrated measurements and downstream scripts support reproduction of Figure 3/4 panel content, Representative Results section 4 and the descriptive PCA summaries.
